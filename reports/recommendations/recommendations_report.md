# Правила рекомендаций

Источник флагов: `flag_thresholds.json`; правила не являются медицинскими рекомендациями. Экспертная валидация не проведена.

## Таблица правил

| code | title | action | rationale | priority | kind |
|---|---|---|---|---|---|
| product_specific | Кластер 0 ограниченно интерпретируем | Учитывайте: кластер 0 в основном сформирован meal_replacement_powder; вывод по нему не переносится на обычные блюда. | Кластер 0 product-specific; это не общий тип питания. | 5 | warning |
| low_fiber | Добавить продукты с клетчаткой | Добавьте порцию овощей, салат или бобовые к этому приёму. | Клетчатка ниже 25-го перцентиля reference-выборки. | 10 | action |
| high_energy_density | Снизить энергоплотность | Добавьте овощи или уменьшите долю жирных соусов, чтобы снизить калорийность на 100 г. | Приём попал в высокоэнергетический кластер 0. | 15 | action |
| low_protein | Добавить источник белка | Добавьте яйцо, рыбу, птицу, тофу или бобовые. | Белок ниже 25-го перцентиля reference-выборки. | 20 | action |
| high_saturated_fat | Заменить часть насыщенных жиров | Замените часть жирного продукта на рыбу, птицу без кожи или растительный источник. | Насыщенные жиры выше 75-го перцентиля reference-выборки. | 30 | action |
| high_sodium | Снизить натрий | Уменьшите соусы, солёные и переработанные продукты; проверьте состав продукта. | Натрий выше 75-го перцентиля reference-выборки. | 40 | action |
| high_sugars | Снизить сахара | Замените сладкий продукт на фрукт или несладкий вариант. | Сахара выше 75-го перцентиля reference-выборки. | 50 | action |
| general_balance | Проверить баланс приёма | Добавьте овощи и источник белка, если их нет в этом приёме. | Явных флагов нет; это общая проверка баланса, не диагноз. | 90 | action |
| no_deviation | Существенных отклонений по правилам нет | Сохраните текущий состав; добавьте овощи, если их обычно мало. | Ни один риск-флаг не сработал. | 100 | action |

## Ограничения

- Флаги сравнивают приём с перцентилями reference, а не с нормами.
- Кластер 0 продукт-специфичный; его предупреждение не является общим выводом о рационе.
- Пропуски нутриентов не трактуются как низкие значения.
- 2–3 рекомендации формируются детерминированно по правилам.
