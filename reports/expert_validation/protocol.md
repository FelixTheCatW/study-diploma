# Протокол экспертной валидации

Выборка: 90 приёмов, стратифицированных по кластеру и удалённости от центроида (near/middle/boundary).

Эксперт не видит номер кластера, расстояние и confidence band.
Нужно отнести приём к одному паттерну или указать «другой» / «не относится», оценить уверенность 1–5 и оставить комментарий.

Метрики после разметки: raw agreement, Cohen's kappa, confusion matrix. Порог для exploratory-вывода: kappa >= 0.5; для уверенного продуктового вывода: kappa >= 0.6.

Ограничения: выборка не является случайной по кластерам; она стратифицирована для проверки интерпретируемости. Результат не является медицинской валидацией.
